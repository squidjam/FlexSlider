Web component · zero dependencies

<flex-slider>

Drop plain images inside an element and it becomes a slider. No jQuery, no stylesheet to load, no build step — the markup and styles live in a shadow root, so nothing leaks in or out.

  • Custom elements v1
  • Shadow DOM
  • Slide & fade
  • Touch & keyboard
  • GPL-2.0

The whole API

Write HTML, get a slider

Every slider on this page is this shape. Attributes are optional; a bare <flex-slider> shows the first image and nothing else. 

<!-- one import, then plain markup -->
<script type="module" src="../flex-slider.js"></script>

<flex-slider animation="slide" autoplay interval="5000" nav pager pause-on-hover>
  <img src="slide-1.jpg" alt="First slide">
  <img src="slide-2.jpg" alt="Second slide">
  <img src="slide-3.jpg" alt="Third slide">
</flex-slider>

01 · Slideshow

Arrows, dots, autoplay

Hover it to pause — pause-on-hover — and the track glides between slides on a CSS transform.

02 · Cross-fade

Fade with a dot pager

Set animation="fade" to stack the slides and cross-fade instead of translating them.

03 · Thumbnails

Thumbnail pager, dark theme, fixed height

pager thumbs builds a thumbnail strip from the same images. height crops to a fixed box with object-fit: cover, so mixed aspect ratios stay tidy.

04 · Vertical

A column instead of a row

direction="vertical" stacks the slides and moves the track up and down. Arrow keys, swipe and the pager all follow the axis.

05 · Scripting it

Methods, properties and events

The element is the API. Every button below drives the slider beside it, and slide-start logs to the panel underneath.

06 · Everything else

Adding an image at runtime

Adding or removing an image updates the slider on its own: it watches its children and rebuilds. Press the button to append a slide to the gallery below.

Reference

Attributes

AttributeValuesNotes
animationslide, fadeHow slides change. Default slide.
durationmsTransition length. Default 700.
easingany CSS timing functionDefault ease.
autoplaypresentStarts a slideshow on load.
intervalmsTime between slides. Default 5000.
pause-on-hoverpresentPauses while the pointer is over it.
navpresentShows the previous/next arrows.
pagerpresentShows the dot or thumbnail pager.
thumbspresentPager renders thumbnails instead of dots.
slide-show-atindex, 0-basedSlide to start on.
directionhorizontal, verticalAxis the track moves along.
reversepresentAnimates the other way.
rtlpresentMirrors arrows and layout.
swipeon, offDrag and swipe. On by default.
keyboardon, offArrow keys, Home and End. On by default.
smooth-heightpresentAnimates the height between slides.
heightCSS lengthFixed box; images crop with object-fit: cover.
themelight, darkArrow and pager colours.
looppresentWraps past the last slide.
labelstringAccessible name for the region.

Methods & events

// methods
slider.next();            slider.prev();
slider.goTo(2);           slider.play();
slider.pause();           slider.refresh();   // re-read the images
slider.reset();           slider.currentIndex = 0;

// events — both carry { index, slide, count } and cross the shadow boundary
slider.addEventListener('slide-start', (e) => console.log(e.detail.index));
slider.addEventListener('slide-end',   (e) => console.log(e.detail.slide));

Theming

/* custom properties, set on the host */
flex-slider {
  --fs-accent: #6db3ff;
  --fs-arrow-bg: rgba(255, 255, 255, .9);
  --fs-arrow-fg: #1f1f1f;
  --fs-dot: rgba(255, 255, 255, .5);
  --fs-dot-active: #fff;
  --fs-radius: 12px;
}

/* or reach in by shadow part */
flex-slider::part(arrow-next) { width: 48px; height: 48px; }
flex-slider::part(frame) { border-radius: 12px; }
